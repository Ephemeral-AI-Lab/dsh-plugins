# 0.1.0

Historical release reconstructed from commits `0c410a6` and `16a20ba` on
2026-08-16.

## Added

- Introduced the initial Codex-style `exec_command` and `write_stdin` plugin,
  originally published in the repository as `bash-codex`.
- Added persistent command sessions with numeric session IDs, stdin delivery,
  output polling, exit-code reporting, timeouts, cancellation, and cleanup.
- Added POSIX shell resolution for macOS/Linux and PowerShell resolution for
  Windows.
- Added PTY-first execution through `node-pty`, with an explicit pipe fallback
  policy when PTY allocation fails.
- Added output decoding, terminal-text sanitization, bounded output retention,
  session capacity limits, and execution-policy validation.
- Added backend, output, policy, session-lifecycle, tool, DSH integration, and
  Windows integration tests.

## Packaging

- Renamed the package and plugin from `bash-codex` to `dsh-codex-shell` while
  retaining version `0.1.0`.
- Added the DSH bundle patch and installation/setup documentation for the
  `codex-shell` loader entry and Codex Whale preset.

## Initial behavior

- PTY transport was the default on all platforms.
- The default configuration allowed 64 sessions, retained up to 1 MiB per
  session, and used a 10-second initial wait with 250 ms polling.
- Windows PTY input used a startup grace period to avoid losing the first
  `write_stdin` input while ConPTY attached.
