# 0.1.4

## Changed

- `exec_command` and `write_stdin` now default to a 4,000-unit output page.
- Added the configurable `maxOutputTokens` hard ceiling, 10,000 by default.
  Larger `max_output_tokens` requests are clamped at the shared session-output
  boundary while unread output remains available to later `write_stdin` polls.
- Tool descriptions and documentation now identify output-token values as
  four-UTF-8-byte estimates rather than exact model-token counts.
- `SPEC.md` is now the authoritative contract for pipe transport, output
  pagination, background-job promotion, notification-inbox delivery,
  ownership, cancellation, and cleanup.

## Validation

- TypeScript typecheck.
- Full serial test suite: 135 passed, 6 skipped.
