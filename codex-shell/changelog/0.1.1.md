# 0.1.1

Historical release reconstructed from commit `5cdbf7c` on 2026-08-16.

## Changed

- Bumped `dsh-codex-shell` from `0.1.0` to `0.1.1`.
- Reworked the setup guide with explicit profile installation, Codex Whale
  preset configuration, verification, and troubleshooting instructions.
- Expanded the interactive-tool documentation to describe the complete
  `exec_command` → `write_stdin` lifecycle and cross-platform usage.

## Fixed

- Made session collection stop treating a session in `terminating` or `closed`
  state as an active wait target.
- Returned an unknown-session error when a session is already closing before it
  has produced a terminal result, instead of waiting indefinitely.
- Updated the lifecycle test to use the resolved platform shell, covering both
  Windows and POSIX stdin/exit behavior rather than assuming `/bin/sh` syntax.

## History note

The package rename from `bash-codex` to `dsh-codex-shell` happened in the
preceding `16a20ba` commit and is therefore recorded in `changelog/0.1.0.md`,
where the package still had version `0.1.0`.
